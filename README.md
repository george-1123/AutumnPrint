# Autumn-ai · Autumn Print

English documentation is the default. [简体中文](docs/zh-CN/README.md)

A 3D printing process and production assistant for individual FDM users, studios, print farms, and enterprise prototyping centers. Personal and enterprise modes share business agents; edge executors run slicing, geometry, and device tools.

Status: personal-mode engineering bootstrap implemented with a durable Fake diagnostic across Electron, API, worker and edge. Production features, installers and full enterprise acceptance remain pending.
