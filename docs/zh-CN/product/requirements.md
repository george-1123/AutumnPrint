# 产品需求

[English](../../en/product/requirements.md) | 简体中文

状态：设计基线，待实现与验证。本文定义用户、目标、范围及成功标准；功能行为见[功能规格](functional-spec.md)，实现方案见[架构总览](../architecture/overview.md)。技术栈、目录和开发顺序不在本文定义。

## 用户与目标

Autumn Print 面向个人 FDM 用户、打印工作室、打印农场与企业打样中心，围绕订单把模型、工艺候选、试打、生产、异常和合格交付关联起来。

用户需要知道：当前订单还缺什么资料，候选方案有什么实际取舍，哪些工艺经过验证，哪些条件变化需要复核，以及交付还缺哪些合格零件。

## 需求基线

| 编号 | 需求 | 成功标准 | 对应功能 |
| --- | --- | --- | --- |
| R-01 | 个人安装软件并配置模型连接即可使用 | 无需搭建服务器或安装开发工具，在界面完成配置并运行样例 | F-01、F-02、F-05 |
| R-02 | 企业成员连接服务器协作 | 成员只访问授权资料，模型由管理员统一配置 | F-01、F-12 |
| R-03 | 本地与企业拥有相同业务 Agent 能力 | 同一业务场景、工具事实和规则可在两种模式验证，允许模型/设备/权限导致能力差异 | F-02、F-05 |
| R-04 | 工艺建议以实际工具结果为依据 | 参数、警告、估算和输入版本可追查，未知能力明确呈现 | F-03、F-04、F-05 |
| R-05 | 保存经过实物验证的工艺 | 测量、装配、批准与适用条件关联，模型/条件改变可复核 | F-06、F-07 |
| R-06 | 正确组织生产和交付数量 | 套件、版本、合格数量和补打缺口可核对，重复事件不增加产出 | F-08、F-09、F-10 |
| R-07 | 长任务不依赖工作台窗口 | 关闭窗口不取消任务，中断后状态可查，外部结果未知先核查 | F-05、F-08 |
| R-08 | 个人和企业资料及设备控制权明确 | 不自动上传/合并个人资料，切换不迁移在途任务或争夺设备 | F-11、F-12 |

## 产品范围

- 模型和订单导入、完整性检查、受控修复候选、真实切片比较。
- 首件试打、实物验收、试验分析、工艺版本与批准。
- 设备与材料、批次安排、异常处理、合格缺口、补打和齐套交付。
- Agent 计划、工具证据、用户等待、恢复、预算与历史记录。
- 个人完整工作区与企业组织协作、角色授权、审计和管理。

## 范围限制

FDM 是当前业务范围。设备接入按实际验证的机型/协议逐项声明，不承诺全品牌控制、所有缺陷自动修复或所有模型 API 完全兼容。模型推理不能代替真实切片、尺寸测量、实物验收或人员批准。其他打印工艺、通用制造认证与无依据的「最佳工艺」不属于当前承诺。

## 用户可见约束

- API 地址、Key 和模型名称通过界面配置；能力检测失败说明原因，不伪装成功。
- 使用远程模型时，获准任务内容会发送给该提供方；本地保存数据不代表本地推理。
- 关机、休眠期间不保证软件执行与监控；恢复后核对设备实际结果。
- 个人与企业工作区不自动同步；迁移需要显式操作与重新核对授权。
- 可处理文件规模、并发、响应时间与支持设备清单需要实测后公布，当前不写入未经验证的数值承诺。
