# 模块化单体控制端与独立现场执行端

[English](../../en/adr/0001-control-plane-and-edge.md) | 简体中文

2026-10-30：部署与工程组织由 [ADR-0002](0002-dual-mode-monorepo.md) 替代。以下保留原决策背景；控制端/现场端职责分离与设备动作核验原则继续适用，统一服务器前提不再适用。

Autumn Print 的业务规则、权限、质量数量与 Agent 编排集中在一个模块化单体中，Orca 子进程、材料/设备读取与获准动作由受管理的现场执行端承接。选择这一结构是为了同时支持 Windows 本地切片和工厂局域网设备、统一企业协作，并避免初期微服务与桌面切片器深度分叉的维护成本；现场端通过出站连接领取限定任务，不直接持有业务数据库权限。

用户工作台采用 Electron，React/TypeScript renderer 经受限 preload 与 main 调用控制端。原生现场端在企业部署中独立运行，关闭窗口不终止切片或设备作业；桌面端不持有设备凭据或代替现场端实施打印控制。

业务任务、动作意图、审批和实物数量以业务记录为准，图执行 checkpoint 与任务队列承担各自执行职责。任何队列重投、图恢复或租约过期都不能直接授权再次启动打印；先检查动作记录和设备实际结果，未知时进入核查。

详细方案见 [技术设计](../architecture/overview.md)。该决策目前是待实现的设计基线，尚未通过真实二进制、设备与部署样例验证。
